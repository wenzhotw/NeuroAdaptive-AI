# 線上示範頁（不需安裝擴充功能）

公開網址：
- 新聞頁：https://wenzhotw.github.io/NeuroAdaptive-AI/
- 購物頁：https://wenzhotw.github.io/NeuroAdaptive-AI/shop/

這兩個示範頁把擴充功能的滑鼠／捲動負荷計算與專注模式直接做進網頁，老師或評審用任何瀏覽器打開就能試。所有資料只在這個分頁計算。

- 介面以繁體中文為主，並附簡短英文說明。
- 預設開啟 Demo 模式（門檻 50、持續 1.5 秒），也可按「直接開啟專注模式」。
- 購物頁是虛構店家「杉海市集」，沒有使用真實品牌標誌；開啟專注模式後搜尋與購物車仍可使用。
- 本工具是自我覺察的輔助，**不是醫療診斷**。

本頁也會一併提交到 `chrome-extension-demo` 分支，並用 GitHub Pages（`gh-pages` 分支）發布。
